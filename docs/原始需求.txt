作品方向
"牛马健康助理"—— 知道你很拼，但不能让你把自己干废
面向久坐办公人群的智能桌面健康提醒小摆件。86盒面板大小，4.2寸电子墨水屏或者MIPI屏幕 + 语音交互 + 振动提醒，放显示器旁边长期驻扎，不帮你干活，专门管你这头牛马的身体。
核心能力：支持唤醒词呼叫，全程接入小米 MiMo API，对话用 mimo-v2.5-flash 解析自然语言指令修改提醒参数，语音播报用 mimo-v2.5-tts 直出音频驱动喇叭，每日战报用 mimo-v2.5-pro 生成毒舌点评推送手机。不需要自建后台，设备直连 MiMo API，一根 Type-C 供电跑起来。
硬件基于 openvela 官方开发板，集成麦克风、喇叭、振动马达、温湿度传感器，Wi-Fi 联网，低功耗长期桌面常驻。

核心功能
久坐分级提醒
 检测在座时长，30/60/90分钟三级响应，振动 + 语音播报 + 墨水屏刷新三重触达。戴耳机靠振动，没戴耳机靠喇叭，眼睛瞎了靠墨水屏，总有一个逃不掉。
AI 语音对话控制
 唤醒词呼叫后，设备录音上传，调用 mimo-v2.5-flash 解析指令，支持说话修改参数。"今天开会多，久坐提醒延长到90分钟"——改。"换一句更损的骂我"——墨水屏内容立刻更新。不用打开App翻设置，说一句话就搞定。
AI 语音播报（MiMo TTS）
 提醒播报直接调用 mimo-v2.5-tts，支持多种中文音色，毒舌风格、温柔风格、丧系风格对应不同音色输出，不是机器人念稿，是真的在说话。
喝水催促系统
 定时提醒 + 每日饮水计数，联网获取本地实时天气动态调整提醒频率。三伏天自动加催，冬天也不放，不是死板的固定闹钟。
护眼提醒
 每40分钟提醒眼睛休息，喇叭播报 + 振动双触达，不点确认不消停。
工位微运动引导
 4.2寸墨水屏展示具体动作图示，颈椎/腰部/眼部轮换，1-3分钟工位原地搞定。扫一眼就知道怎么动，不用找视频不用占手机。
每日收工战报
 汇总今日久坐时长、喝水次数、运动完成率，调用 mimo-v2.5-pro 生成个性化毒舌点评，同步推送手机App。自己看自己的数据，自己惭愧。
闲时内容轮播
 天气、节气、MiMo 动态生成毒舌语录，屏幕不空着，桌面存在感常驻。不提醒的时候也在那戳你。
手机App配套
 设置各项提醒间隔和目标值、查看每日报告和历史趋势、切换提醒文案风格（温柔版 / 毒舌版 / 丧系版）。

创新亮点
1. 全程接入 MiMo API，一个平台搞定所有 AI 能力
 对话理解用 mimo-v2.5-flash，语音播报用 mimo-v2.5-tts，战报生成用 mimo-v2.5-pro，设备端直接 HTTP 调用，不自建后台，不依赖第三方服务，完整体现 MiMo 生态在 IoT 硬件场景的落地能力。
2. 振动 + 语音 + 墨水屏三重提醒，物理级存在感
 软件推送可以划掉，手机通知可以静音，但桌上这个东西在震、在说话、在显示。专门针对戴耳机、开会、专注状态的打工人，三种方式叠加，总有一个能触达，这是纯软件提醒产品根本做不到的。
3. 语音 AI 对话，参数修改零门槛
 不只是"智能提醒"，是真的能对话。通过 MiMo 解析自然语言指令，映射到本地配置修改和内容刷新。正在干活不想分心？说一句话就改，不用摸手机。
4. 毒舌人格 + AI 动态生成文案，长期不疲劳
 固定文案看久了就屏蔽了，接入 MiMo 动态生成每日新语录，同一个场景每次说法不一样。配合风格切换，长期使用也能保持新鲜感，提醒还是那个提醒，但每次都还是有点想笑。
5. 天气联动，提醒策略自适应
 接入实时天气数据，高温高湿自动加密喝水提醒频率，不是拍脑袋定的固定间隔，有点真的在照顾你的感觉。同时体现了 IoT 传感器数据与云端服务联动的完整设计思路。
6. 电子墨水屏 + Type-C 供电，整机峰值功耗约 1.2W
 不抢眼、不费电、不伤眼，和"健康"定位本身一致。一根手机充电线接电脑 USB 口就能跑，不需要额外电源。墨水屏静止零功耗，适合长期桌面常驻，不会用着用着就嫌它烦拔电源。
 一句话总结：它不管你卷不卷，就管你喝没喝水、腰有没有断。
