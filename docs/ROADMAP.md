## 工具流程债务（待实施，不冒充已修复）

| 项 | 验收方向 |
|---|---|
| snapshot 覆盖不全、失败仍继续、全量暂存 | 按实际受影响仓固化，失败即停，绑定验证范围，显式暂存 |
| `/data/vela` 脚本不随当前四仓恢复 | 纳入受控版本并建立可验证的安装/恢复流程 |
| run-emu 宽泛 kill、修改生成 ini | 目标进程隔离、配置源追溯、有效模式实测 |
| wrap/日志按工具和工作区限定不足 | 当前 session 可追溯导出、范围门控、非零事件校验 |
| 构建目标可能共享生成头/状态 | 对真实编译命令验证；证实污染后再选隔离方案 |
