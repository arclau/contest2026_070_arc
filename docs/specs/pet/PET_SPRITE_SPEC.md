# 🐱 电子宠物精灵图完整需求文档（96帧 = 12状态 × 8帧）

> **全部重新生成**，不复用旧图。
> **平台**：R528 + NuttX + LVGL 9
> **转换流程**：256×256 PNG → 项目工具转成 C 数组（ARGB8888 300×300）→ 编入固件

---

## 通用规格

| 项目 | 要求 |
|------|------|
| **尺寸** | **256×256 像素**（严格） |
| **格式** | **PNG，8-bit RGBA**（与现有 `tools/pet_prompts/cat_v3/` 一致） |
| **背景** | **全透明**（Alpha=0） |
| **风格** | 像素风（Pixel Art），2-3px 清晰描边，圆润可爱，小体型（占画布约60-70%） |
| **主体色** | 橙色虎斑 #E8A248 |
| **腹部色** | 奶白 #FFF5E0 |
| **耳内/鼻/肉垫** | 粉色 #FFB6C1 |
| **眼睛** | 圆眼 #2D2D2D，高光 #FFFFFF |
| **描边** | 深棕 #5C3A1E |
| **帧率** | 8帧循环 @240ms/帧（约4.2fps） |
| **命名** | `pet_cat_{状态}_{序号}.png`，序号 `00`~`07` |
| **输出路径** | `tools/pet_prompts/cat_v3/` |
