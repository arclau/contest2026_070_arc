# V1 UI 材质与资源优化方案

> 目标平台：`ynm3000`，BOE 1200×1920 面板横屏使用（1920×1200），应用 `luncher_dm`。
> 2026-10-27 用户更新目标：在改造架构的同时，恢复 Home 与锁屏接近 iOS 26 的半透明玻璃质感，并降低资源占用。本方案取代 P289 的“视觉零变化”约束；P289 的既有事实与验证记录保留。
> 本轮用户明确要求停止继续截图；视觉方向依据旧 devlog 和现有代码，实机观感留给板端复核。

## 目标与验收

1. Home 的天气、健康、音乐卡及锁屏的健康卡能看出背景透过卡面；边缘干净，文字、图标和进度环仍清楚。
2. 卡片材质有统一入口，页面只保留必要的局部差异。视觉调整不改导航、数据更新和锁屏交互。
3. 不采集新截图。用旧 devlog 定义设计方向，静态检查配方；最终色彩、触摸与流畅度由 V1 板端验证。
4. 分开报告运行堆峰值、刷新耗时、页面切换耗时、固件/资源体积。没有数据时不宣称“省内存”或“更流畅”。

## 当前事实与问题

- V1 `style_card` 使用 90% 白底、无边框和轻黑影；Home 背景是浅灰渐变。两者太接近，玻璃视觉层次消失。锁屏健康卡复用该样式，双圈容器另有一套 60% 白底配方。
- P271 的方向是淡彩背景透过半透明白卡、细白边和对称柔影；同时记录了贴图方角、硬边色块接缝及 RGB565 横带等代价。V2 `dm_theme_card_apply` 的配方仅模拟玻璃，没有背景模糊；V2 整套配方不直接搬到 V1。
- V1 当前有一套共享 `lv_style_t`，但其余页面仍有大量逐对象样式。主题层能统一设计，节省 RAM/绘制时间必须测量。
- 1920×1200、32 位画面每帧约 8.8 MiB；这属于显示预算，整理样式不会消除。SIM 是 RGB565，浅色渐变可能出现量化色带，不能据此判断板端观感。

## 设计方向

以 P271 的透底层次为基础，接近 iOS 26 的视觉原则：背景能透过卡面、圆角边缘有高光、卡面浮在背景上且文字可读。Home 与锁屏共用一张蓝、青、薄荷色大圆弧连续渐变的 1920×1200 壁纸，半透明中性白卡配细白边和对称柔影；原全屏淡彩渐变作为资源缺失时的退路。不用卡内渐变条纹、平铺磨砂 PNG、实时模糊或持续动画。它是静态视觉近似，不能宣称有 iOS 的实时折射。

参考：[P271 材质实验](../../devlogs/10-17-glass-material-and-wash.md)；[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。Apple 的系统材质有动态折射与自适应能力，V1 此轮只实现适合本设备预算的静态近似。

| 元素 | 第一轮处理 | 后续选择依据 |
|---|---|---|
| Home/锁屏共享卡 | 恢复半透明白、细白边、对称柔影；保留布局 | 板端复核透底与文字对比 |
| 页面背景 | 同一张全屏壁纸作底层，渐变作退路 | 板端复核与卡片、文字的对比；SIM 资源随 UI 交付同步 |
| 锁屏双圈/欢迎卡 | 保留尺寸和交互，收敛为相同材质参数 | 板端复核圆角、点击和唤醒 |
| 其他页面 | 第一轮不动 | 逐页抽 card/text/row/button/icon 样式 |

## 分阶段实施

1. **基线**：记录当前源码/有效配置/ELF 与可获得的堆、导航和刷新数据。P290/P271 的视觉证据只作历史参照。本轮停止新截图与模拟器窗口操作。
2. **材质整改**：先集中 Home/锁屏共享卡与背景配方；代码、构建结果和待板端复核的观感分开记录。锁屏需要验证进入、唤醒、再次进入。
3. **主题与组件**：把定稿配方集中为 V1 共享样式或材质函数，再逐页消除重复。只把真正相同的组件合并，动态状态/尺寸仍由页面负责。
4. **资源优化**：先量测再处理高占用项；分别评估字体与图片缓存、宠物资源、无变化时的重复 UI 更新。页面缓存只用于实测收益明显的高频页面，必须给出 RAM 代价。
5. **视觉精修**：按 Home → 锁屏 → 设置/音乐 → 其余页面的顺序调整空状态、文字层级、对齐和图标。每页单独确认观感与功能。

## 每阶段交付门槛

- 保存涉及文件、变量、预期、构建与运行证据；无板端视觉证据时标为待复核，不能宣称观感通过。
- goldfish 构建与页面操作通过后，最终共享代码补 `ynm3000` 构建、打包、资源校验；板端未测单列。
- 不使用 V2 的独立源码树作为 V1 补丁来源；不借材质任务改导航或触摸驱动。

## 壁纸资源预算

- 板端源文件：`vendor/allwinnertech/lichee/board/r528s3/ynm3000_nand/data/res/wallpaper/blue-hour.png`，RGB PNG，1920×1200，约 1.97 MB；Home 和锁屏使用同一路径，没有第二份图片或背景子对象。模拟器另在 `vendor/openvela/boards/vela/prebuilts/data/wallpaper/` 放同内容资源，两目标各有一份。
- LVGL PNG 解码器使用 ARGB8888，单次全图解码约 9.2 MB（1920×1200×4 字节）；是否常驻、缓存复用与堆峰值尚未在板端实测，因此不能把压缩文件大小当成运行内存。
- 本次是视觉资源新增，不宣称资源总量下降。后续资源优化仍以实测堆峰值和刷新耗时为准。
