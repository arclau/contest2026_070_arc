# 主页面 UI 布局规格（1440×720 横屏）— 定稿草稿 v1

> **状态**：主页面布局**已定稿**（2026-10-14），进入新 UI 适配准备阶段。
> **源文件**：`/data/vela/nav/deskmate.html`（浏览器预览 `http://<private-ip>/deskmate.html`）
> **用途**：这是新屏主屏（HOME）的唯一布局依据；C/LVGL 实现按本文件的尺寸/配色/字号落地。
> **关联**：`AGENTS.md` §一.5（源码结构）、`devlog.md` P243。

## 0. 一句话

主屏 = **顶部状态栏** + **三栏**（左：信息 / 中：入口 / 右：宠物）。
**左栏（时间 + 健康）最重要**；**宠物不做主角**（用户 2026-10-14 明确定位）。

## 1. 设计基准

| 项 | 值 |
|---|---|
| 目标屏 | **1440 × 720 横向**，5.7 英寸，带触摸 |
| 观看距离 | 约 40cm（桌面摆件） |
| 物理→逻辑 | **DM_SCALE = 2.0**，逻辑画布 **720 × 360**（物理值 ÷2） |
| 字号下限 | 正文 ≥ 32px 物理（≈3mm），低于此在 40cm 看不清 |
| 设计语言 | Liquid Glass：白卡 + 玻璃模糊 + 大圆角 + iOS 配色 |

> 旧的 1920×1200（1.6:1，scale 2.4）**不再支持**，直接替换（用户 2026-10-14 拍板）。

## 2. 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│ 10月14日 周三          📶 Vela-WiFi   ᛒ   76%▮                │  ← 状态栏 58px
│ (居中于左栏)          (整屏居中)                               │
├──────────────┬──────────────────────────┬────────────────────┤
│              │  下午好，小刘             │                    │
│    14:32     │  今天也是元气满满的一天   │  小橘  Lv.3        │
│              │                          │  ┌──────────────┐  │
│  (hero时钟)  │                          │  │   宠物舞台    │  │
├──────────────┤  ┌────┐┌────┐┌────┐┌────┐ │  └──────────────┘  │
│  ◯  久坐      │  │音乐││日历││书籍││文件│ │                    │
│              │  └────┘└────┘└────┘└────┘ │  饱食度 ▓▓▓▓░      │
│  ◯  喝水      │  ┌────┐┌────┐┌────┐┌────┐ │  心情   ▓▓▓░░      │
│              │  │AI  ││设置││UART││锁屏│ │                    │
└──────────────┴──────────────────────────┴────────────────────┘
   左 372            中 600（弹性）            右 372
```

- 左栏：状态栏下方依次 **hero 时钟卡**（flex 固定）+ **健康双圈卡**（flex 撑满）
- 中栏：**问候钉顶** + **8 个入口图标贴底**（`margin-top:auto`）
- 右栏：**宠物舞台**整列常驻
- 状态栏：**日期居中于左栏**（宽 372），**WiFi/蓝牙/电量整屏居中**

## 7. 新 UI 适配落地步骤（对应二次开发 P1/P2）

1. **建 token 层**：在 `deskmate_ui.h` 引入 `DM_SCALE = 2.0` 与布局 token（间距/字号/圆角），把本文件第 3/5 节的值全部落成宏，禁止散落裸像素。
2. **新屏驱动点亮**（P2，依赖面板型号/触摸 IC 信息）：新 mipi_config + lcd panel + Kconfig，守 `AGENTS.md` §四.2 互斥；新屏原生横向 → **删 degree0 旋转 workaround**。
3. **主屏重构**：按本文件重写 `ui_home.c`（状态栏 / 时钟卡 / 健康卡 / 入口网格 / 宠物舞台），旧 1920×1200 布局与硬编码一并清除。
4. **自证**：编译打包 → `check_res.sh` → 上板 40cm 实测字号可读性。

## 8. 待定 / 风险

| 项 | 说明 |
|---|---|
| 面板型号 / 触摸 IC | 用户单独提供（P2 前置，缺则驱动无法点亮） |
| 是否同板换屏 | 未知；决定只改面板配置还是要动板级 |
| 字体 | HTML 用系统字体；板端需选 Montserrat + 中文字体，字号需按实际字宽微调（142px 时钟已接近左栏宽度上限） |
| 宠物素材 | 现为 SVG 占位；真素材需高分辨率（右栏 372×~600），依赖「宠物 PNG 进 res」管线 |
| 中栏 8 入口 | 对 5.7" 偏多，后续若嫌挤可减到 6 + 「更多」 |
| 交互态 | 本稿只有静态布局；点击态/子页切换/弹窗未画 |
