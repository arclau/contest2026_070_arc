## 0. 一句话定位

彩色触控版"牛马健康助理"——放在桌上长期驻扎，**接近传感器自动感知人坐下/离开**，用「锁屏双圈 + 语音播报」管久坐和喝水，按住圈就能语音对话。豆包大模型全家桶（LLM/ASR/TTS）设备直连，无自建后台。

## 2. 在座感知（dm_presence / dm_health 核心）

接近传感器（`sensor_prox`，luncher_dm.c 已订阅，可读距离 cm）：

| 事件 | 判定 | 动作 |
|---|---|---|
| 坐下 | 距离 ≤ 30cm **持续 5s**（防抖） | 会话开始：双圈重置，喝水/久坐计时启动 |
| 离开 | 距离 > 30cm **持续 20s** | **所有计时清零**（用户拍板），弹窗收起 |
| 回来 | 重新满足坐下条件 | 重新开始（清零语义） |

防抖原因：伸手碰屏/猫走过/弯腰捡物均为瞬时抖动，稳住才算。

## 3. 喝水提醒（默认 45min，天热缩 30min）

| 档位 | 触发 | 触达 | 按钮 |
|---|---|---|---|
| L1 | 坐下满 45min | 锁屏弹窗（小卡）"该喝水啦" | 左"我喝了" / 右"先不喝" |
| L2 | 点"先不喝"后 15min | 大弹窗 + **AI 语音**："亲爱的牛马哟，该喝水了" | 同上 |
| L3 | 再不喝后 15min | 全屏弹窗 + 毒舌语音（按风格档文案） | 同上 |

- "我喝了" → 喝水次数 +1（战报数据）、计时重置；
- "先不喝" → 不计数、进下一档；
- 天气联动：气温 ≥ 30℃ 时 45min → 30min（复用 dm_weather 链路）。

## 4. 久坐提醒（同套路）

| 档位 | 触发 | 触达 | 按钮 |
|---|---|---|---|
| L1 | 连续在座 30min | 弹窗"起来活动一下吧" | 左"我起来了" / 右"继续坐" |
| L2 | 60min | 大弹窗 + AI 语音 | 同上 |
| L3 | 90min | 全屏 + 毒舌语音 | 同上 |

"我起来了" → 久坐清零 + 喝水也重置（起来=顺便喝水）；"继续坐" → 进下一档。

## 5. 锁屏布局（standby 改造）

```
┌────────────────────────────┐
│ 大时钟            温湿度    │
│                            │
│   [喝水圈 45']  [久坐圈 30']│   ← 两个倒数环，显示剩余分钟
│                            │
│           ◎                │   ← AI 语音圈（两圈下方居中）
│        按住说话             │
└────────────────────────────┘
```

- 保留：大时钟、日期、温湿度、音乐控件（现状已有）；
- 双圈：LVGL arc 倒数环，左边喝水（蓝系）、右边久坐（橙系）；
- AI 圈：复用现有 PTT 语音交互，锁屏直接按住说话 → AI 回复播报+上屏；AI 子页保留不动。

## 6. 每日战报

传感器实测在座时长（"今日坐了 6h20m"为真实数据）+ 喝水次数 + 起立次数，屏上展示。

## 7. 数据持久化

`/data/dm_health.state`（yaffs，仿 dm_music.state 模式）：今日喝水次数、起立次数、累计在座时长、风格档位。
