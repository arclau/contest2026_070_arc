# P360 天气预报图标重绘（96px / 分色 / 抗锯齿）

目标：把天气卡里那排"破图标"改成有颜色、有细节的图形。
平台：V1 `ynm3000` / `luncher_dm`（1920×1200，DM_SCALE 2.4）。

## 一、旧实现的问题

`ui/ui_home.c` 的 `draw_weather_glyph()` 是 64×64 canvas 逐像素画的：

1. **尺寸太小**：卡片宽 840px，5 个日格均分后每格 152px，64px 图标只占 42%，远看就是个小灰块。
2. **几乎没颜色**：云一律 `0xC7C7CC` 灰，阴天/雾/雨/雪的云完全相同，只能靠下面几根线区分。
3. **硬边锯齿**：`cv_fill_circle` / `cv_line` 整数像素直写，斜线圆弧一圈台阶。
4. **雪分支不可达**：`code 51..82`（雨）写在 `71..86`（雪）前面，71/73/75/77/85/86 全被雨吃掉。

## 二、改动

`deskmate_ui.h` 新增 `DM_WICON_SIZE 96`，缓冲与绘制共用；`w_icon_buf` 从 `deskmate_ui.c`
移到 `ui_home.c`（deskmate_ui.c 不含该头文件）。5×96×96×4 = 184,320 B，BSS +102,400 B。

绘制层重写：写 `uint32_t` 缓冲 + `lv_obj_invalidate()`（省掉逐像素 `lv_canvas_set_px`，
也才能自己做 alpha 叠加）；圆/圆角矩形/粗线算覆盖率做抗锯齿，闪电 4×4 超采样；
云 = 3 圆 + 圆角矩形取并集（圆并集画不出平底）+ 竖向渐变 + 下移 5px 柔和投影；
分色：晴=琥珀+光晕+8 光芒；多云=太阳从云后露出；雨=宝石蓝带浅蓝高光（毛毛雨短、
阵雨长）；雪=冰蓝六角雪花带短枝；雷暴=紫云+金黄闪电；雾=灰蓝云+三条渐弱横线。
判定顺序改成先雪后雨，修掉雪分支不可达。不读 NAND、不引图片资源，只在建卡与
天气刷新（2h）时重绘，不在渲染热路径上。

## 三、验证

主机端离线渲染（同一份绘制代码，`gcc -O2`，20 个天气码拼一张图）：
0/1/2/3/45/48/51/55/61/65/71/73/75/77/80/82/85/86/95/96 全部按预期出图，
雪花、闪电、双层云 2× 放大下边缘平滑。只证明"画得对"，不证明"装在卡里合身"。

构建 `pack_deskmate.sh ynm3000` PASS（config / entrypoint / startup / 121 resources /
nsh / whole image），`nm` 里 `w_icon_buf` = 0x2d000 = 184,320 B 与设计一致。
镜像 `output/ynm3000/ynm3000.img` 53,149,696 B，MD5 `a2599d82b305b269e0ec2b0f81a933d6`。

待验（板上）：① 5 个日格是否都出图、有没有被裁；② 真实天气下颜色够不够醒目
（卡片浅玻璃底，云用"上白下蓝灰"）；③ 天气卡高度不变，不挤动下方卡片。
