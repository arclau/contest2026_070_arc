# P318 — V1 宠物交互优化：轻量悬浮胶囊与触控防抖

2026-10-31。目标平台 R528 `ynm3000`，V1 1920×1200。
目标：彻底根治宠物交互弹窗“点击不了/难触发/笨重违和”的 UX 体验问题。

## 一、交互重构与 Bug 根治

1. **拖拽死区放宽（8px → 20px）**：
   - 修复在 1920×1200 高清电容屏上手指肉体微动即被判定为拖拽（DRAG）导致清空点击计数的问题。
2. **废除笨重系统确认框（dm_popup_card）**：
   - 原弹窗长达 743px，包含删除式大图标与长文本，违和且易误触外沿触发唤醒主屏。
   - 改为轻量级**悬浮毛玻璃胶囊（`[ 喂鱼 ]` | `[ 逗猫 ]`）**，尺寸精致紧凑，紧贴猫头顶浮动。
3. **点击逻辑极大简化（单触即出，再触收起）**：
   - 单击猫咪立即触发蹭蹭反馈并呼出操作胶囊；
   - 胶囊弹出期间强制猫咪停止走动原地等待，彻底避免按钮滑动漂移；
   - 再次轻触猫咪或 6 秒无操作自动收起胶囊。
4. **即时响应与爱心反馈**：
   - 点击“喂鱼”使用 `dm_pet_on_input` 立即消费事件并切动作，不再有 200ms 异步排队延迟；
   - 吃鱼弹出“好吃！♥”专属气泡；
   - 修正了 `hunger` 饱食判定条件（`hunger <= 10` 提示吃饱，原逻辑相反）。
