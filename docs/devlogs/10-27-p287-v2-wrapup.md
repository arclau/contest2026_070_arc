## 1. 决定

- **V2 触摸停止投入**。接受"可点按、拖动断触"的现状，不再做单变量实验。
- 交付重心转向 **V1 兜底**（`ynm3000`：BOE 1200×1920 + GT9271 + `luncher_dm`）。

## 2. 停止依据：R5 实验关闭了 INT 路线

| 项 | 内容 |
|---|---|
| 唯一变量 | `hx83102_pins_config()` 中 INT 的 pull：`GPIO_PULL_DOWN_DISABLED` → `GPIO_PULL_UP` |
| 动机 | 历史日志扫描：E2（上拉 ON）是唯一出现 `INT 1 -> 0` / `INT 0 -> 1` 的版本；E5 关掉上拉后所有版本 INT 零跳变 |
| 机理 | 模组 INT 在 1.8 V 域且无电平转换，R528 PB5 属 3.3 V 域、VIH≈2.31 V；关内部上拉后只剩 1.7 V，永远读低 |
| 结果 | **刷机后花屏，比 R4s 更差**，已回退 |
| 结论 | 3.3 V 强上拉打到 1.8 V 模组侧会扰动面板，与 E2（RST 推挽 3.3 V 出横纹）同型。**INT 的软件解法关闭** |

剩余路径只有两条：

1. **硬件改线**：加电平转换，或 3.3 V 上拉串限流电阻。决赛前来不及，记为下一步。
2. **接受无 INT**：继续盲轮询，拖动断触作为已知边界写进答辩口径。

### 3.1 顺带修通的一键入口

`tools/check_deskmate.py` 原要求 `CONFIG_ARCH_BOARD_{PRODUCT}` 显式存在，但该符号是
`bool default y`，`savedefconfig` 必然删除，导致 `pack_deskmate.sh` 对两个产品都必然 FAIL
（两产品目录此前均无 `manifest.json`，说明从未跑通）。已改为该派生符号缺失时容忍，
`ARCH_BOARD_CUSTOM_DIR` 仍严格校验；两线 defconfig 互换喂给对方预检均被拦下，隔离强度未削弱。
原件备份：`output/ynm3000/check_deskmate.py.before-split-fix`。
