## 二、关键排障发现

### 1. 驱动 lux 偏低根因
- activate() 写 INTEG_50MS（50ms 积分），但 lux 系数按100ms 基准
- CH0/CH1 原始值只有100ms 的一半 → lux 偏低一半
- 修复：加 int_factors[]/gain_factors[] 校正表（与 Android 同芯片驱动一致）
- **同时发现 activate() 不同步 struct 字段**（init 设100ms，activate 写50ms 但 struct 还是100ms）→ 一并修复

### 2. ratio≥0.85 归零
- LTR-553ALS-01 datasheet 算法：ratio≥0.85 返回0（CH0≈CH1 时无法区分光谱）
- 真实暗光环境 CH0=11,CH1=11 → ratio=1.0 → 永远0 lux
- 修复：CH0<200 时用 `0.1 × CH0 × correction` 最小估算

### 3. 暗光弹窗三重拦截
| 拦截层 | 条件 | 修复 |
|--------|------|------|
| P157 确认门 | 需见过 ≥200 lux | 移除（传感器已清洁） |
| LD2410B 检测 | `dm_ld2410b_present() ≤ 0` 不弹 | 移除（独立于人体检测） |
| 弹窗尺寸为0 | flex column 未计算高度 | `lv_obj_set_size` 显式设置 |

### 4. 弹窗 w=0 h=0 根因
- `lv_obj_set_width` 在 `lv_obj_set_flex_flow` 之前调用
- flex flow 设置时重置了宽度→弹窗0尺寸→不可见
- 修复：flex flow/flex_align 先设，再 `lv_obj_set_size(DM(500), DM(300))`
