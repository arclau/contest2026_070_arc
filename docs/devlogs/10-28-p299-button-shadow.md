# P299 — V1 目录图标与返回按钮边框/阴影测试

> 目标：V1 `ynm3000` 文件浏览器，目录图标和左上角返回按钮增加默认边框与阴影，供用户刷机比较立体感。无截图；观感待验。
>
> **结论（2026-10-29 用户板测）：否决并回滚。** 用户反馈“文件浏览器返回和本机下的图标阴影好丑，还不如不改”。两处样式已恢复实验前状态，见文末「回滚」。

## 唯一实验变量：两类对象的边框与阴影样式

- `ui_files.c:files_refresh_list`：目录徽章不再覆盖 `border_width=0`，沿用 LVGL 默认对象边框；阴影改为默认浅色按钮配方的灰色、`lv_dpx(3)` 宽、50% 不透明度、`lv_dpx(4)` 向下偏移。非目录文件徽章沿用原样式。目录共用构建路径，因此 TF 卡目录和子目录也受影响。
- `deskmate_ui.c:dm_subpage_back_btn_show`：删除禁用阴影的局部设置，恢复按钮主题阴影；补默认对象同款边框 `lv_dpx(2)`、`lv_palette_lighten(GREY, 2)`。全子页共用此按钮，影响不限于文件页。
- 预期：目录边缘更清楚，灰色下投影与底色区分；返回按钮呈现边框与下投影。布局、回调和销毁路径不变。
- 补丁暂留供用户测试；本轮前的两份 C 文件和独立差异保存于 `output/p299-v1-button-shadow/`，可只撤销本轮实验。
